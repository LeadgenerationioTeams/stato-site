How it works

Workflows, integrations and stack.

Workflows & automations

  • Multi-step forms with branching logic
  • A/B tests with a declared winner taking over
  • An optional consent tick box that records the exact wording seen
  • Per-step drop-off tracking without tag management
  • Leads pushed to the customer's CRM as they arrive

Integrations

  • LeadByte
  • Make and Zapier
  • Webhooks
  • Meta and Google tracking IDs
  • MCP connector for AI assistants

Tech stack

  • Next.js on Vercel
  • Supabase (PostgreSQL) with row-level security

How it was built and tested

  • Released in small, versioned updates with release notes
  • Every release gets a UX check on mobile and desktop
  • Production checked after each release
